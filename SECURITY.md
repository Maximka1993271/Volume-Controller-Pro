# Security Policy

## Supported version

Report the affected Volume Controller Pro version. The current release is listed on the [Releases page](https://github.com/Maximka1993271/Volume-Controller-Pro/releases).

## Reporting a vulnerability

Do not publish exploit details, private data, or proof-of-concept code in a public issue.

1. If GitHub's **Report a vulnerability** / private vulnerability reporting option is enabled for this repository, use it.
2. If it is unavailable, open a public issue containing only a brief request for a private channel. Do not include technical details there.

Please include the affected version, browser/version, impact, reproduction outline, and possible mitigations. Remove personal information, session tokens, and unrelated browsing data from logs and screenshots.

There is no guaranteed response time. Please allow the maintainer time to investigate and prepare a fix before public disclosure.
