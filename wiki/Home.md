# Volume Controller Pro

**Volume Controller Pro 4.8.31** is a Manifest V3 browser extension for volume control, audio enhancement, and real-time audio visualization in Microsoft Edge and compatible Chromium browsers.

## What it provides

- Master volume from 0% to 600%.
- Bass Boost up to +12 dB and Voice Boost up to +8 dB.
- Per-site audio profiles for supported YouTube and Spotify Web Player pages.
- Peak Limiter and Night Mode.
- Automatic genre detection using title context and broad audio-spectrum profiles.
- Seven spectrum visualizer styles and a configurable spectrogram.
- Light, Dark, and System appearance modes, plus English, Russian, and Ukrainian interface languages.
- Local settings storage and `.cfg` backup import/export.
